## Play

The live game is hosted with GitHub Pages (see URL in the repo's About section once Pages is enabled).

Or open `index.html` directly in any modern browser — no install, no internet needed.

## Deploy your own

1. Repo Settings → **Pages** → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
2. The game goes live at `https://<your-username>.github.io/atm-go/`.
3. On Android Chrome: ⋮ menu → **Add to Home screen** → **Install** for the full app experience (works offline via the service worker).

## Files

- `index.html` — the complete game (single file)
- `manifest.json` — PWA manifest
- `icon.svg` — app icon
- `sw.js` — offline service worker
